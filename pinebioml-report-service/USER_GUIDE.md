# PineBioML AI Report User Guide

Welcome to the PineBioML AI Report viewer! This guide is designed to help researchers, clinicians, and data scientists navigate and interpret the automated machine learning analysis generated by our platform.

## 1. Overview of the Report

When PineBioML finishes processing your dataset (e.g., Breast Cancer Wisconsin), it compiles quantitative metrics, visual graphs, and mathematical feature importance (SHAP) into a single cohesive narrative.

### The Single-Page Application (SPA) Viewer
The report is hosted in an interactive, glassmorphic HTML layout.
- **Self-Contained**: The report is a single `.html` file. You can download it and share it offline. All images, CSS, and JavaScript are embedded.
- **Exportable**: You can export the report to PDF or Word (DOCX) using the endpoints provided by the API.
- **Secure Sharing**: To view the report, users must be provided with the unique `access_token` generated by the API. Without this token, the report is securely blocked. Shareable links automatically expire after 30 days (by default) to ensure patient data remains private.
- **Real-Time Streaming**: During generation, the viewer will display an interactive, live-streaming preview of the AI's reasoning process as it streams directly from the local LLM.

## 2. Expert vs. Layperson Mode

One of the most powerful features of the PineBioML Report is the **Dual-Audience Narrative Engine**.
At the bottom right of the screen, you will find a floating toggle switch.

* **Expert Mode (Default)**: Displays rigorous statistical interpretation, model comparisons, and SHAP value breakdowns. This is intended for data scientists or clinical researchers evaluating the robustness of the ML pipeline.
* **Layperson Mode (zh-TW)**: Clicking the toggle switches the narrative into Traditional Chinese. It hides complex metrics (like ROC-AUC and MCC) and provides a highly simplified, patient-centric summary of what the model discovered and why it matters.

## 3. How to Read the AI Analysis

### Executive Summary
A high-level overview generated by the DeepSeek-R1 reasoning engine. It confirms the dataset analyzed, the task type, and provides a quick verdict on whether the best model achieved statistically significant results.

### Key Findings
A bulleted list of 5 critical takeaways derived from the data. This highlights the most predictive features and any surprising correlations found.

### Model Comparisons
Expert mode provides a comprehensive data table of all models evaluated during the PineBioML run, with precise fractional scores across all key metrics (Accuracy, ROC-AUC, F1, MCC). Layperson mode condenses this into an easy-to-read vertical bar chart of the top performing models, focusing only on core accuracy.

### Feature Importance (SHAP)
This section explains *HOW* the model makes decisions. 
- The AI interprets the SHAP (SHapley Additive exPlanations) values to explain which features push the model toward a specific classification.
- For example, if analyzing breast cancer data, it might explain that a higher `mean_radius` significantly increases the probability of a malignant classification.

### Visualization Gallery
Click on any plot (Confusion Matrix, ROC Curve, PCA, UMAP) to zoom in. The AI provides a written critique of these plots—for instance, analyzing whether cluster boundaries in a UMAP projection are well-defined or overlapping.

## 4. Interactive Features

### Glossary Tooltips
Don't recognize a term like **AUC** or **MCC**? 
Hover your mouse over any dashed-underline terminology in the text. A sleek floating tooltip will appear with the definition, making the report accessible to interdisciplinary teams.

### Content-Editable Sections
We know AI isn't perfect, and clinical expertise is irreplaceable.
- **Executive Summary** and **Recommendations** sections are fully editable in the browser.
- Simply click on the text box (which will highlight with a glowing border) and type your own clinical notes or technical next steps before printing the report or sharing your screen!

## 5. Understanding Limitations and Hardware Constraints

### Overfitting Warning
At the bottom of the report, pay close attention to the **Overfitting Warning**.
Our DeepSeek-R1 Chain-of-Thought pipeline explicitly checks for "Near-Perfect Accuracy" (e.g., 99.9% or 100%). If it detects this, it will flag the model as a high risk for overfitting, warning you that the results may not generalize well to unseen real-world data.

### CPU Fallback
If the system experiences high concurrency or if the GPU VRAM is completely saturated by other PineBioML training jobs, the microservice may seamlessly fall back to CPU inference. The report will generate successfully, but you may see a badge indicating CPU generation, and the generation time may increase.
